\# Student Knowledge Assistant Platform



A full-stack, AI-powered web application designed to help students quickly access accurate information through natural language questions.



\## Features

\- Student-facing React UI for submitting questions

\- Node.js \& Express backend with REST APIs

\- AI-powered responses using a Large Language Model (LLM)

\- Secure API key management via environment variables

\- Interaction logging for audit and analytics readiness

\- Health check endpoint for system monitoring



\## Tech Stack

\- Frontend: React (Vite)

\- Backend: Node.js, Express

\- AI: OpenAI API

\- Tooling: Git, npm

\- Architecture: Routes, Controllers, Services pattern



\## Real-World Workflows

\- Student inquiry handling

\- AI-assisted response generation

\- Interaction logging for compliance and analytics

\- System health monitoring
